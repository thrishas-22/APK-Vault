**APK Vault**
A web-based APK hosting platform developed as an academic project. The application allows users to upload, manage, and download Android APK files through a web interface.

**Technologies Used**
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP (Apache & MySQL)

**Features**
- User authentication
- APK file upload and management
- Database-driven application
- Responsive user interface

**How to Run**
1. Install XAMPP.
2. Copy the project folder into the "htdocs" directory.
3. Import the database into MySQL.
4. Start Apache and MySQL from XAMPP.
5. Open the project in your browser using "http://localhost/".
